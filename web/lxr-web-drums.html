LXR Web Drums

Sechs Drum-Stimmen nach dem Vorbild der Sonic Potions LXR, als Web-Audio-Modul für den X-Generator. Dieselben Stimmen und Parameter wie die LXR-Engine der ONE-CLICK-Firmware für den FM-1.

Pattern · ein Takt, 16 Steps

Zelle anklicken setzt oder löscht einen Schlag, der Lane-Name spielt ihn einzeln. CP ist die Snare-Stimme als Clap, CH stoppt OH.

Stimme

Einbau in den X-Generator

  1. lxr-drums.js in die HTML-Datei der App kopieren (oder als Script-Tag einbinden).
  2. Beim Start der Audio-Engine eine Instanz an den Master hängen.
  3. Im Scheduler für Drum-Spuren mit Engine „LXR“ die Lanes auslösen.
  4. Beim WAV-Export eine zweite Instanz im OfflineAudioContext mit demselben Kit anlegen.
// 2. beim Start
this.lxr = new LxrDrums(this.ctx, this.master);        // würfelt ein Kit

// 3. im Scheduler (time = Startzeit des Steps)
if (tr.engine === "LXR") {
  // Kick-Spur: "BD", Snare-Spur: "SD", Percussion: "TM" / "RS" / "CB" …
  this.lxr.trigger(tr.lxrLane || "BD", time, tr.vel ?? 0.8, step.accent);
}

// Sound-Box „neu würfeln“
this.lxr.randomize();
this.lxr.set("KICK", "DECAY", 90);                      // 0..127

// 4. WAV-Export (OfflineAudioContext)
const lxrOff = new LxrDrums(off, master, this.lxr.toJSON());
lxrOff.trigger("BD", noteStart, tr.vel);
